# 🚌 Public Transport Performance and Passenger Analysis using Power BI

## 📌 Project Overview

This project focuses on analyzing **public transport performance and passenger data using Power BI**.

The dashboard provides insights into passenger activity, transport performance, revenue-related metrics, and operational trends through interactive visualizations and KPIs.

## 🎯 Project Objectives

* Analyze overall passenger activity.
* Evaluate public transport performance.
* Identify passenger trends and patterns.
* Analyze transport-related KPIs.
* Compare performance across different categories.
* Identify important business insights using interactive dashboards.

## 🛠️ Tools & Technologies

* **Power BI**
* **Power Query**
* **DAX**
* **Data Visualization**
* **Data Analysis**

## 🔄 Project Workflow

1. Data Import
2. Data Cleaning using Power Query
3. Data Transformation
4. Data Modeling
5. DAX Measures
6. KPI Creation
7. Dashboard Development
8. Business Analysis
9. Insights & Conclusion

## 📊 Dashboard

The Power BI dashboard contains interactive visualizations and KPI cards to analyze public transport performance and passenger behavior.

Key dashboard components include:

* KPI Cards
* Charts
* Slicers
* Tables / Matrix
* Performance Analysis
* Passenger Analysis
* Trend Analysis

## 💡 Key Insights

The dashboard helps identify:

* Passenger activity and trends.
* Transport performance patterns.
* Differences across transport categories.
* Important performance indicators.
* Areas that can support better operational decision-making.
